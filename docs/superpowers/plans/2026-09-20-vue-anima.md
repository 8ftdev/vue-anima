# vue-anima Implementation Plan

> Execute inline using the executing-plans workflow; review the finished library independently.

**Goal:** Ship a small Vue and Vapor directive for reversible reactive WAAPI goal styles.
**Architecture:** A shared DOM controller owns only animated properties. Separate Vue and Vapor exports adapt reactive updates. Optional resolvers translate class goals into style maps.
**Tech Stack:** Bun, TypeScript, Vue 3.5 and 3.6 RC, ESLint, Prettier, Playwright, Vite.
**Spec:** `docs/superpowers/specs/2026-09-20-vue-anima-design.md`

## Global constraints

Use Bun exclusively. Name package vue-anima and directive v-anima. ESM, Vue external, no runtime dependencies. Strict types and lint. Core gzip budget 2 kB. Verify actual compiled Vue and Vapor fixtures. No publishing.

## Decisions

The workspace is empty and is not a Git repository, so implement directly here without creating a worktree or making commits. User approved the single-directive options object; omit the earlier optional configuration directive. Reject invalid timing/unsupported class inputs clearly. Compatibility claims name exact tested versions.
